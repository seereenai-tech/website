# SeereenAI

SeereenAI is a luxury AI brand experience focused on agents, automation, SaaS platforms, custom software, and intelligent business systems. This project is a cinematic single-page marketing site designed to feel like a premium digital story rather than a standard startup landing page.

## Project overview

This app builds a polished marketing experience for SeereenAI with:

- a warm desert-inspired aesthetic
- premium glassmorphism panels and layered depth
- cinematic scroll storytelling
- editorial typography and generous whitespace
- custom sections for philosophy, services, products, process, and contact
- subtle motion and atmospheric transitions to evoke a premium brand presence

The site is implemented as a Vite + React + TypeScript app with TanStack Router and a custom design system.

## Tech stack

- React 19
- TypeScript
- Vite
- TanStack Router
- Tailwind CSS
- Radix UI primitives
- Framer Motion / motion
- Lucide icons

## Project structure

- src/routes — route definitions and page metadata
- src/components/scenes — narrative sections for the landing page
- src/components/ui — reusable UI primitives
- src/components/atmosphere.tsx — ambient glow and atmospheric effects
- src/assets — brand images and logo assets
- src/styles.css — theme and brand styling

## Features

- immersive hero section with premium desert atmosphere
- layered narrative storytelling across scroll sections
- service cards and product presentations
- premium brand messaging aligned with SeereenAI positioning
- responsive layout for desktop, tablet, and mobile
- performance-conscious motion and lightweight UI patterns

## Local development

Requirements:

- Node.js
- npm

Install dependencies:

```bash
npm install
```

Run the app locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Notes

- The brand direction follows the supplied SeereenAI visual identity and luxury desert aesthetic.
- The implementation intentionally avoids generic SaaS layouts and instead emphasizes atmosphere, story, and premium product presentation.
- This repository is connected to Lovable and is intended to be developed as a polished brand showcase experience.
